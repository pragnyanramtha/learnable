**1. What does File I/O mean?**
A. Reading from and writing to files | B. Matching only text patterns | C. Creating classes only | D. Repeating a loop forever
<Answer: A. Reading from and writing to files>
<Explanation: File input reads saved data, and file output writes data for later use.>

**2. In `open("names.txt", "a")`, what does `"a"` mean?**
A. Analyze | B. Append | C. Average | D. Argument
<Answer: B. Append>
<Explanation: Append mode adds new content to the end of the file.>

**3. Why is `with open(...)` often preferred?**
A. It automatically handles cleanup like closing the file | B. It deletes the file after reading | C. It turns every file into a CSV | D. It prevents loops
<Answer: A. It automatically handles cleanup like closing the file>
<Explanation: The `with` block closes the file when the block finishes.>

**4. What kind of data does a CSV file usually store?**
A. Row-and-column style data | B. Only Python functions | C. Only image bytes | D. Only regular expressions
<Answer: A. Row-and-column style data>
<Explanation: CSV files are common for spreadsheet-like data.>

**5. Why is `csv.DictReader` useful?**
A. It lets rows be read using column names | B. It only reads binary files | C. It removes all duplicate values | D. It replaces every loop
<Answer: A. It lets rows be read using column names>
<Explanation: With headings, each row can be treated like a dictionary.>

**6. What is a regular expression mainly used for?**
A. Matching text patterns | B. Closing files | C. Creating global constants | D. Drawing graphics
<Answer: A. Matching text patterns>
<Explanation: Regex describes shapes or patterns that text should match.>

**7. Which Python module is commonly used for regular expressions?**
A. re | B. csv | C. math | D. random
<Answer: A. re>
<Explanation: Python's regular expression tools are in the `re` module.>

**8. In many regex patterns, what does `^` represent?**
A. The start of the string | B. The end of the string | C. Any number | D. A file path
<Answer: A. The start of the string>
<Explanation: `^` anchors a match to the beginning of the text.>

**9. Why should input often be cleaned before regex matching?**
A. Extra spaces or case differences can affect matches | B. Regex cannot read strings | C. Cleaning deletes the need for patterns | D. Regex only works on numbers
<Answer: A. Extra spaces or case differences can affect matches>
<Explanation: Methods like `strip()` and `lower()` make matching more predictable.>

**10. What is a set useful for in Python?**
A. Storing unique values | B. Keeping every duplicate in order | C. Replacing all functions | D. Reading image files only
<Answer: A. Storing unique values>
<Explanation: Sets are useful when membership and uniqueness matter.>

**11. What does a type hint do?**
A. It describes expected input or output types | B. It runs code automatically | C. It creates a file | D. It removes docstrings
<Answer: A. It describes expected input or output types>
<Explanation: Type hints improve clarity for people, editors, and checking tools.>

**12. What is the purpose of a docstring?**
A. To explain what code does in human language | B. To append text to a file | C. To sort a list | D. To force a constant never to change
<Answer: A. To explain what code does in human language>
<Explanation: A docstring documents a function, class, module, or method.>

**13. What does `*args` collect?**
A. Extra positional arguments | B. Only dictionary keys | C. Only filenames | D. Exception messages
<Answer: A. Extra positional arguments>
<Explanation: `*args` gathers extra positional inputs into a tuple.>

**14. What does `**kwargs` collect?**
A. Extra keyword arguments | B. Only list indexes | C. Only file modes | D. Only regex matches
<Answer: A. Extra keyword arguments>
<Explanation: `**kwargs` gathers named inputs into a dictionary.>

**15. What is one benefit of a generator?**
A. It can produce values one at a time and save memory | B. It always returns all values at once | C. It deletes duplicates automatically | D. It replaces every string with a regex
<Answer: A. It can produce values one at a time and save memory>
<Explanation: Generators are useful when values can be processed lazily.>
